根目录作为整个工程的编排中心：package.json 的 dev 脚本使用 concurrently 并行启动 dev:main（tsc -p tsconfig.main.json 编译主进程 + wait-on 等待 Vite 5173 端口就绪后启动 electron）与 dev:renderer（vite 开发服务器），build 流程先 tsc 再 vite build 产出 dist，最后由 electron-builder 基于同一份 dist/dist-electron 输出 Windows/macOS/Linux 安装包。index.html 是 Electron 加载的入口页面，React 应用挂载于 #root，@ 别名指向 src 目录。tsconfig.json 对 src 启用 strict + isolatedModules + react-jsx，所有子模块（electron/、src/domain/、src/application/、src/infrastructure/、src/components/、src/renderer/、src/i18n/、src/types/）共享同一 TypeScript 配置与路径别名，确保跨进程类型一致。渲染层按 DDD 分层：domain 为纯领域逻辑（图谱布局、差异解析、主题预设），application 为 Zustand 状态与用例编排，infrastructure 提供渲染侧 gitBridge 网关，components 与 renderer 构成界面层。
