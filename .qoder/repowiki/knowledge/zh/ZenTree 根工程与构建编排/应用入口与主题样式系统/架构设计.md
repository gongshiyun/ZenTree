模块由四个文件构成清晰的职责分层：`src/main.tsx` 是 React 应用唯一入口，通过 `ReactDOM.createRoot` 将 `<App />` 渲染到 `#root` 节点并包裹在 `React.StrictMode` 中，同时导入 `theme.css` 和 `App.css`；`src/App.tsx` 作为顶层容器组件，根据 `useRepoStore.currentRepo` 决定渲染 Welcome 欢迎页或完整工作区（TopBar/Sidebar/CommitGraph/FilePanel/DiffPanel/CommitBar/StatusBar/SettingsDialog），并通过 `window.gitAPI` 与 Electron main 进程交互（打开目录、读取设置等）；`src/theme.css` 集中声明所有 CSS 自定义属性（颜色、字体、圆角、阴影等），通过 `[data-theme="light"]` 选择器实现暗色/亮色主题切换；`src/App.css` 按功能区域组织样式（top-bar、sidebar、center-area、diff-panel、commit-bar、status-bar、welcome、settings-dialog、context-menu 等）。依赖方向单向：main.tsx → App.tsx → components/stores，样式通过 CSS 变量解耦主题与布局。
